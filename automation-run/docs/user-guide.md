## Начало работы

### Регистрация

1. Перейдите на сайт automation.run
2. Нажмите кнопку "Регистрация"
3. Введите email, пароль и имя
4. Подтвердите email (опционально)

### Личный кабинет

После входа вы попадаете в личный кабинет, где видите:
- **Dashboard** - обзор активности
- **Автоматизации** - список ваших workflow
- **История запусков** - логи выполнений
- **Подписка** - управление тарифом
- **Настройки** - настройки профиля

## Создание автоматизации

### Шаг 1: Создание нового workflow

1. Нажмите "Новая автоматизация"
2. Введите название и описание
3. Вы попадете в визуальный редактор

### Шаг 2: Добавление узлов

1. В левой панели выберите нужный узел
2. Перетащите его на холст
3. Повторите для всех нужных узлов

### Шаг 3: Соединение узлов

1. Наведите на выход узла (точка внизу)
2. Перетащите линию к входу следующего узла
3. Линия соединит узлы

### Шаг 4: Настройка параметров

1. Кликните на узел
2. В правой панели настройте параметры
3. Используйте переменные для динамических значений

### Шаг 5: Активация

1. Нажмите "Сохранить"
2. Нажмите "Активировать"
3. Workflow готов к работе!

## Триггеры

### Webhook

Запуск по HTTP-запросу. После активации вы получите уникальный URL.

**Параметры:**
- Метод: GET, POST, PUT

**Пример использования:**
```
POST https://api.automation.run/webhook/your-unique-id
Body: { "data": "value" }
```

### Расписание

Запуск по cron-расписанию.

**Параметры:**
- Cron выражение (например: `0 9 * * *` - каждый день в 9:00)
- Часовой пояс

**Примеры cron:**
- `*/5 * * * *` - каждые 5 минут
- `0 */2 * * *` - каждые 2 часа
- `0 9 * * 1-5` - в 9:00 по будням
- `0 0 1 * *` - 1 числа каждого месяца

### Получение Email

Запуск при получении письма.

**Параметры:**
- Фильтр по отправителю
- Фильтр по теме

## Действия

### Отправка Email

**Параметры:**
- Кому: email получателя
- Тема: тема письма
- Текст: содержимое (поддерживает HTML)

### Telegram сообщение

**Параметры:**
- Chat ID: ID чата или пользователя
- Сообщение: текст (поддерживает HTML/Markdown)

**Как получить Chat ID:**
1. Напишите боту @userinfobot
2. Он пришлет ваш ID

### Slack сообщение

**Параметры:**
- Канал: #channel или @user
- Текст: сообщение

### HTTP запрос

**Параметры:**
- URL: адрес запроса
- Метод: GET, POST, PUT, PATCH, DELETE
- Заголовки: JSON объект
- Тело: данные запроса

### Google Sheets

**Параметры:**
- Действие: append (добавить), read (прочитать), update (обновить)
- ID таблицы: из URL таблицы
- Диапазон: например, "Sheet1!A:D"
- Данные: значения для записи

## Логика

### IF/ELSE (Условие)

Ветвление потока по условию.

**Параметры:**
- Левый операнд: значение для сравнения
- Оператор: equals, not_equals, contains, greater_than, less_than, is_empty, is_not_empty
- Правый операнд: с чем сравниваем

**Выходы:**
- Да (true) - условие истинно
- Нет (false) - условие ложно

### Задержка

Пауза перед следующим шагом.

**Параметры:**
- Длительность: число
- Единица: секунды, минуты, часы

### Цикл

Итерация по массиву данных.

**Параметры:**
- Источник: путь к массиву
- Макс. итераций: лимит (по умолчанию 100)

### Преобразование

Трансформация данных.

**Операции:**
- map - преобразование элементов
- filter - фильтрация
- json_parse - парсинг JSON строки
- json_stringify - конвертация в JSON
- to_upper - в верхний регистр
- to_lower - в нижний регистр

## Переменные

### Синтаксис

Используйте `{{path.to.value}}` для вставки динамических значений.

### Доступные переменные

- `{{trigger.body}}` - тело запроса триггера
- `{{trigger.headers}}` - заголовки
- `{{nodeId.output}}` - результат узла
- `{{variables.name}}` - пользовательская переменная

### Примеры

```
Email получателю: {{trigger.body.email}}
Сообщение: Привет, {{trigger.body.name}}!
Результат: {{http_request_1.data.result}}
```

## Примеры автоматизаций

### 1. Уведомление о новом заказе

**Триггер:** Webhook (POST от сайта)
**Действия:**
1. Send Email (уведомление менеджеру)
2. Send Telegram (в рабочий чат)
3. Google Sheets (добавление в таблицу)

### 2. Ежедневный отчет

**Триггер:** Schedule (каждый день в 18:00)
**Действия:**
1. HTTP Request (получение данных из CRM)
2. Transform (форматирование)
3. Send Email (отчет руководству)

### 3. Обработка формы обратной связи

**Триггер:** Form Submission
**Логика:**
1. IF/ELSE (проверка типа обращения)
   - Если "жалоба" → Email в отдел качества
   - Иначе → Email в поддержку
2. Google Sheets (сохранение всех обращений)

### 4. Мониторинг сайта

**Триггер:** Schedule (каждые 5 минут)
**Действия:**
1. HTTP Request (проверка доступности)
2. IF/ELSE (статус != 200)
   - Да → Send Telegram (алерт)
   - Нет → ничего

## FAQ

### Как отладить автоматизацию?

1. Используйте кнопку "Тестировать" в редакторе
2. Проверяйте логи в разделе "История запусков"
3. Раскройте детали каждого шага

### Почему автоматизация не запускается?

1. Проверьте, что она активирована
2. Проверьте лимиты тарифа
3. Убедитесь в правильности триггера

### Как получить больше выполнений?

Перейдите на тариф Pro или Enterprise в разделе "Подписка".
